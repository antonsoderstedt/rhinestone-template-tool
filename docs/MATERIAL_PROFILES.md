# Material Profiles — Rhinestone Template Tool

## Overview

Material profiles define the physical constraints that govern how stones are placed for a given material. Different materials stretch, compress, or resist differently — so hole sizing and spacing must be tuned per material.

---

## Magic Flock (Primary Target Material)

Magic Flock is a heat-transfer flock material designed for rhinestone templates. When cut by a Cricut Maker 3 and rhinestones are pressed in, the material grips the stones.

### Properties Relevant to Hole Sizing

| Property | Value | Notes |
|----------|-------|-------|
| Material stretch | Low | Flock has minimal stretch compared to HTV |
| Minimum edge spacing | 0.508 mm | Minimum material required between any two hole *edges* (`minimumEdgeSpacingMm`) |
| Recommended safety margin | 0.25 mm | Additional gap added on top of the physical minimum center distance |

Hole diameters are vendor (TRW) verified per stone size and live in
`MAGIC_FLOCK_HOLE_PRESETS` (`profiles/materialProfiles.ts`) — this is the
single source of truth; see ADR 0004 in `docs/decisions/`.

| Stone size | Hole diameter | Status |
|------------|---------------|--------|
| SS6  | 2.54 mm | Verified |
| SS8  | 3.00 mm | Verified |
| SS10 | 3.43 mm | Verified |
| SS12 | 3.80 mm | **Provisional** — no verified vendor source; calibrate before production use |
| SS16 | 4.39 mm | Verified |
| SS20 | 5.28 mm | Verified |

### Default Profile

```typescript
const MAGIC_FLOCK_CRICUT_MAKER_PROFILE: MaterialProfile = {
  id: 'magic-flock-cricut-maker',
  name: 'Magic Flock',
  cutter: 'Cricut Maker 3',
  supportedStoneSizes: ['SS6', 'SS8', 'SS10', 'SS12', 'SS16', 'SS20'],
  defaultStoneSize: 'SS10',
  spacingSafetyMarginMm: 0.25,
  minimumEdgeSpacingMm: 0.508,  // mm between hole edges — see getMinimumCenterDistance
  kerfCompensationMm: 0,        // set after physical calibration
  scaleCompensationPercent: 0,  // set after physical calibration
  requiresCalibration: true,
  holePresets: MAGIC_FLOCK_HOLE_PRESETS,
  machineRecommendations: [MAGIC_FLOCK_CRICUT_MAKER_3_RECOMMENDATION],
};
```

### Machine Cut Settings (Cricut Maker 3)

Machine settings are cutter-specific, not template geometry — changing them
never affects hole diameter or spacing. `MAGIC_FLOCK_CRICUT_MAKER_3_RECOMMENDATION`:

| Setting | Value |
|---------|-------|
| Blade | Deep-Point Blade |
| Custom pressure | 350 |
| Pressure | More |
| Passes | 1 |
| Multi-cut | Off |
| Mirror | No |
| Liner | Remove before cutting |
| Mat | StrongGrip (or another high-tack mat) |
| Test cut | Mandatory before production |

An alternative custom pressure of **340** is available for older/thinner
Magic Flock batches — it requires its own test cut and is never the primary
recommendation.

### Calibration Override Support

The engine now supports **calibration overrides** via `createCalibrationOverrideSet` and `applyCalibrationOverridesToTemplate`. After physically testing hole diameters with the calibration sheet, you can create an override set and apply it to any template before export:

```typescript
const overrides = createCalibrationOverrideSet({
  id: 'my-setup',
  name: 'My calibrated settings',
  materialProfileId: 'magic-flock-cricut-maker',
  overrides: [
    { stoneSize: 'SS10', holeDiameterMm: 2.9 },  // measured, not provisional
  ],
});

const calibrated = applyCalibrationOverridesToTemplate(template, overrides);
```

Calibrated stones receive metadata: `calibrated: true`, `calibratedHoleDiameterMm`, `originalHoleDiameterMm`.

Overrides are in-memory only in the current sprint. Persistent saved profiles are planned.

## Why Calibration is Required

Magic Flock reacts to the Cricut blade pressure and speed in ways that vary by:
- Blade age
- Mat condition
- Ambient temperature and humidity

A freshly calibrated profile ensures that the holes cut in the real world match the dimensions designed in the tool. **Do not use default offsets for production runs without running the calibration workflow first.**

See `docs/CALIBRATION_PLAN.md` for the calibration procedure.

### Calibration Sheet Integration

The calibration sheet is generated by `createCalibrationSheet(profile)` and exported via `createBasicSvgExport()` — the same pipeline used for production templates. Each hole in the sheet stores its tested diameter in `stone.metadata.testedHoleDiameterMm` and its variant label in `stone.metadata.variantLabel`, so the SVG is fully self-documenting. After cutting, you can identify the correct column by trying each hole and updating `kerfCompensationMm` in the profile.

### Spacing Safety Margin and Density Controls

The `spacingSafetyMarginMm` in the Magic Flock profile (0.25 mm) is added on top of the
physical minimum center distance (`getMinimumCenterDistance` — see ADR 0004) to give the
recommended center distance. The density presets work as follows relative to this:

- `safe`: adds a further 0.25 mm gap above the recommended distance.
- `standard`: uses the recommended distance (includes the safety margin).
- `dense`: reduces spacing by 0.15 mm below recommended but never goes below the physical minimum (excludes the safety margin, but stays physically safe).
- `loose`: adds 0.5 mm above the recommended distance.
- `custom`: caller must supply a value ≥ the physical minimum.

For Magic Flock with SS10 (hole diameter 3.43 mm, `minimumEdgeSpacingMm` 0.508 mm):
- Physical minimum center distance = 3.43 + 0.508 = 3.938 mm
- Recommended = 4.188 mm (3.938 + 0.25 margin)
- `safe` = 4.438 mm
- `standard` = 4.188 mm
- `dense` = 4.038 mm (4.188 − 0.15 = 4.038 ≥ 3.938, no clamping)
- `loose` = 4.688 mm

## Profile Data Location

Material profile constants live in:

```
/src/lib/rhinestone-engine/profiles/
```

Each material has its own file, e.g. `magic-flock.ts`. The engine reads the active profile from the user's selected configuration.
